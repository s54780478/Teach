# idaltu - 在地家教與技能媒合平台 (MVP)

以全球最大實體技能媒合平台 **Superprof** 為核心架構參考，為台灣在地化（面授到府 / 線上視訊）打造的現代技能與家教媒合平台原型。

---

## 🌟 核心特色與架構

1. **極簡品牌 Header (`Header.tsx`)**：
   - 品牌標誌：`idaltu`（純文字小寫、極簡幾何風，搭配活力珊瑚紅識別點）。
   - Superprof 核心膠囊型雙核心搜尋列：
     - **想學什麼**（如：國中數學、吉他、JLPT 日文、React）。
     - **上課地區**（如：台北市大安區、新北板橋、新竹東區）。
     - **授課方式即時切換**（全部 / 實體面授 / 線上視訊）。

2. **導師卡片網格 (`TutorCard.tsx`)**：
   - 包含 8 位高質感的在地頂大師資與專家假資料（台大物理碩士、倫敦 UCL 語言學碩士、清大資工、師大數學、早稻田大學日籍外師、Berklee 音樂等）。
   - **學歷與身分已驗證標章 (Verified Badge)**：醒目的官方驗證標章與學歷標記。
   - **專長標籤 (Specialty Tags)**：例如 `#國中數學`、`#台大物理系`、`#會考衝刺`。
   - **地區標籤 (Location Tag)**：標示 `台北市大安區 / 可線上` 等實體與遠端支援。
   - **鐘點學費 & 首堂免費試教**：Superprof 代表性的 `🎁 首堂免費試教` 誘因設計。
   - **「解鎖聯繫 (Contact Tutor)」互動按鈕**：點擊即可彈出預約諮詢視窗。

3. **雙向互動與即時篩選**：
   - 即時響應式網格（Desktop 4欄/3欄，Mobile 單欄堆疊）。
   - 類別快速切換膠囊（數理升學、外語學習、程式設計、音樂藝術）。
   - 排序功能（推薦排序、最高評價、時薪高低）。
   - 彈出式「解鎖聯繫」預約表單，支援即時送出回饋。

---

## 🚀 本地端啟動方式

```bash
# 安裝依賴 (如已安裝可略過)
npm install

# 啟動開發伺服器
npm run dev
```

開啟瀏覽器前往：`http://localhost:3000`
